# Бот

А. Найти подмножество людей по подстроке.
/search
Ввод: строка
Вывод: кол-во найденных человек/ничего не найдено
Кнопки: на каждого человека + пагинация

Б. Статистика по лагерю.
/stats
Ввод: nil
Вывод:

ОБЩИЙ ОТЧЁТ ПО ЛАГЕРЮ (вложенность)
1. Участник/оргкомитет
2. Статус
3. Округ (если есть)

ОТЧЁТ ПО ЛАЗАРЕТУ:
1. ФИО + №команды + роль
2. Количество

ОТЧЁТ ПО УЕХАВШИМ
1. ФИО + №команды + роль
2. Количество

ОТЧЁТ УСПЕНСКОГО
1. ФИО + №Команды + Статус
